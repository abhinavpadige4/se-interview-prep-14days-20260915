# 14-Day Software Engineering Interview Preparation Plan

This repository contains a comprehensive 14-day plan to prepare for Software Engineering interviews, covering:
- Data Structures and Algorithms (DSA)
- System Design
- Behavioral Interview Preparation
- 20 solved LeetCode problems with solutions
- Curated resources for each topic

## Repository Structure

│   ├── problem1.py

## How to Use This Repository
1. Follow the daily schedule in `schedule.md`
2. Study the concepts using resources in `resources.md`
3. Practice the 20 selected LeetCode problems
4. Refer to solution files for guidance and best practices
5. Track your progress through the 14-day plan

## Topics Covered
- **DSA**: Arrays, Strings, Two Pointers, Sliding Window, Binary Search, DFS/BFS, DP, Heap, Graph, Trie
- **System Design**: Basics, Scalability, APIs, Databases, Caching, Load Balancing
- **Behavioral**: STAR method, Leadership principles, Conflict resolution, Teamwork
